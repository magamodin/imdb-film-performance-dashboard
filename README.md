# 🎬 IMDb | Film Performance Dashboard

Microsoft Excel istifadə olunaraq sıfırdan hazırlanmış, film sənayesinin maliyyə və performans göstəricilərini təhlil edən interaktiv analitik idarəetmə paneli (Dashboard).

---

## 🚀 Layihə Haqqında
Bu layihə film sənayesində gəlir, mənfəət və reytinq göstəricilərini vizuallaşdırmaq, həmçinin illər və onilliklər üzrə müqayisəli təhlillər aparmaq məqsədilə qurulmuşdur.

* **Əsas Göstəricilər (KPIs):**
  * **Ümumi Gəlir (Total Gross):** $1,514.9B
  * **Ümumi Mənfəət (Total Profit):** $1,072.4B
  * **Mənfəət Marjası (Profit Margin):** 70.79%

---

## 📊 Dashboard Xüsusiyyətləri və Vizuallar

1. **Onilliklər Üzrə Filtrləmə (Slicer):** 1980-ci illərdən 2020-ci illərə qədər zaman aralığını dinamik şəkildə dəyişdirmək imkanı.
2. **Total Gross vs Profit vs Profit Margin:** İllər üzrə gəlir, mənfəət və marja dinamikasının müqayisəli xətt və sütunlu qrafiki.
3. **Total Gross by Country:** Ölkələr üzrə (Almaniya, Türkiyə, Kanada, Azərbaycan, Fransa, UK, USA) ümumi gəlir bölgüsü.
4. **Top 5 Profit Share by Genre (%):** Janrlara görə mənfəət payı bölgüsü (Sci-Fi, Action, Romance, Thriller, Comedy).
5. **Top 5 Loss by Director:** Ən çox zərər edən rejissorların analizi.

---

* **Microsoft Excel:** Qabaqcıl düsturlar, Pivot Table / Pivot Charts, Dinamik Slicer-lər və Şərti Formatlaşdırma.
